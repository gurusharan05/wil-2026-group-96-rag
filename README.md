# International Student RAG Assistant

## About the Project

Our project aims to develop a **Retrieval-Augmented Generation (RAG) assistant** to help prospective and current international students in Australia make informed decisions about studying and living in Australia.

The assistant will focus on three key areas:

**Course and university selection**
**Student accommodation**
**Part-time work rights**

It will use information from **official university, course, accommodation and Australian government sources** to provide reliable, grounded and **source-cited answers** instead of generic AI-generated advice.

## Project Aim

> Our project builds a Retrieval-Augmented Generation (RAG) assistant that helps prospective and current international students in Australia navigate key decisions around choosing a course and university, student accommodation, and part-time work rights, combining official course, fee, and government guidance to give grounded, source-cited answers rather than generic advice.

## How It Will Work

The system will retrieve relevant information from trusted sources and use it as context for generating answers.

Trusted Sources
      ↓
Knowledge Base
      ↓
Information Retrieval
      ↓
Relevant Context
      ↓
     RAG 
      ↓
Answer with Sources

## Key Goals

* Provide accurate and relevant information to international students.
* Ground responses in reliable sources.
* Provide citations so users can verify the information.
* Reduce unsupported or hallucinated responses.
* Evaluate the effectiveness and reliability of the RAG system.

## Evaluation

The project will use a **test-driven evaluation framework** to measure how well the system performs. Evaluation will consider factors such as answer correctness, retrieval effectiveness, faithfulness and source attribution.

## Project Status

**In Development**

The project is currently in the early development and research stage. The RAG approach, knowledge sources, evaluation framework and final prototype will be developed throughout the project.
